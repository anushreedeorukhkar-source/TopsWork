2.Write a short explanation (2-3 sentences each) for the following: What is the difference between an error, a bug, and a defect? Give one real-world example for each from any app you use daily (e.g., Instagram, Paytm, IRCTC).
Answer : 
a) Error
An error is a mistake made by a person while crearing the software, such as a developer writing the wrong code or a tester misunderstanding a requirement.
Example - In the Instagram app a developer writes the wrong code, so the "Like" button does not work properly. This mistake is called an error.

b) Bug
A bug is a problem in the application that the users or testers can see while using it. It makes the app behave in an unexpected way.
Example - User entered the correct UPI PIN, but the app freezes and the payment doesn not happen. This problem is a bug.

c) Defect
A defect is a confirmed problem where the app does not work as it is supposed to according to the requiremnts.
Example - User successfully pays for train ticket but doesn't get booked. Since the app did not do as it was expected to do, this is called a defect.

4.Imagine you are testing a new food delivery app (like Swiggy). List 3 types of risks that could affect the quality of the app before launch (for example: security risk, usability risk, performance risk). For each risk, briefly explain how it could impact users.
Answer :
a) Security Risk
A security risk means user's personal or payment information is not properly protected.
Example: If the app is not secure, hackers could steal users' personal details or payment information, causing users to lose trust in the app.

b) Performance Risk
A performance risk means the app is slow, crashes, or takes too long to load.
Example: Users may not be able to place orders quickly, and they may leave the app and use another food delivery service instead.

C) Usability Risk
A usability risk means the app is difficult to use or understand.
Example: If users cannot easily search for restaurants, add items to the cart, or complete payment, they may get frustrated and stop using the app.
